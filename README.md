# Праздник.яр — PWA

## Публикация через GitHub Pages
1. Создай публичный репозиторий `prazdnik-yar`.
2. Загрузи в корень репозитория все содержимое этой папки, включая папку `icons`.
3. Открой Settings → Pages. В разделе Build and deployment выбери Deploy from a branch, ветку `main`, папку `/ (root)`, затем Save.
4. Дождись публикации. Адрес будет `https://ТВОЙ-ЛОГИН.github.io/prazdnik-yar/`.
5. Открой ссылку на телефоне. Android: меню браузера → Установить приложение / Добавить на главный экран. iPhone: Safari → Поделиться → На экран Домой.

## Важно
- PWA требует HTTPS (GitHub Pages его предоставляет).
- Первый запуск требует интернета. После него Service Worker кэширует страницы приложения и часть ресурсов.
- Данные в localStorage сохраняются только в этом браузере и на этом устройстве. Для общей базы пользователей, заказов, расписания и платежей понадобится сервер и база данных.
- Внешняя карта и изображения из сторонних сервисов могут требовать интернет.
- После изменения файлов увеличивай CACHE_NAME в `service-worker.js` (например, v2), чтобы обновить кэш.
